# ChatGPT DONE Auto-Continue for Microsoft Edge

Небольшое Manifest V3 расширение для Microsoft Edge, которое автоматически продолжает работу в ChatGPT.

## Что делает

Расширение следит за текущей вкладкой `chatgpt.com` и отслеживает состояние генерации ответа.

Логика:

1. ChatGPT начинает генерировать ответ.
2. Расширение видит кнопку остановки генерации.
3. Генерация заканчивается.
4. Расширение ждёт заданную задержку и проверяет, что текст ответа стабилен.
5. Если последняя непустая строка ответа — ровно `DONE`, расширение автоматически отправляет:

```text
Делай следующее задание
```

Если в поле ввода уже есть твой текст, расширение ничего не перезаписывает и не отправляет.

## Установка в Microsoft Edge

1. Скачай репозиторий как ZIP или клонируй его.
2. Если скачал ZIP — распакуй его.
3. В Edge открой:

```text
edge://extensions/
```

4. Включи **Режим разработчика / Developer mode**.
5. Нажми **Загрузить распакованное / Load unpacked**.
6. Выбери папку этого репозитория — ту, где лежит `manifest.json`.
7. Обнови уже открытые вкладки ChatGPT.

Сборка, Node.js и установка зависимостей не нужны.

## Настройки

Нажми на иконку расширения в Edge. Можно изменить:

- включено ли автопродолжение;
- маркер завершения (`DONE` по умолчанию);
- сообщение, которое отправляется дальше;
- задержку после окончания генерации.

Настройки применяются к уже открытым вкладкам без перезагрузки.

## Рекомендуемая инструкция для ChatGPT

Добавь в основной промпт примерно такое правило:

```text
Когда текущая задача полностью выполнена и можно без моего участия переходить
к следующей задаче, последней непустой строкой ответа напиши ровно:

DONE

Не пиши DONE, если есть блокер, нужен мой ввод, подтверждение или решение.
```

## Важное поведение

Расширение специально **не отправляет сообщение просто потому, что при открытии старого чата последний ответ заканчивается на DONE**. Оно должно увидеть текущую генерацию, а затем её завершение. Это защищает от случайного запуска старых чатов.

Если расширение было установлено, пока ответ уже был полностью сгенерирован, запусти следующую генерацию вручную один раз. После этого цикл будет отслеживаться автоматически.

## Поддерживаемые сайты

- `https://chatgpt.com/*`
- `https://chat.openai.com/*`

## Как определяется генерация

Расширение использует DOM-индикаторы интерфейса ChatGPT, в первую очередь кнопку `data-testid="stop-button"`. Для отправки используются актуальные селекторы `#prompt-textarea`, `#composer-submit-button` и `data-testid="send-button"` с запасными вариантами.

Интерфейс ChatGPT периодически меняется. Если OpenAI изменит DOM-разметку, селекторы в `content.js` может потребоваться обновить.

## Безопасность и приватность

- Никаких API-ключей.
- Никакого внешнего сервера.
- Никаких сторонних библиотек.
- Расширение работает локально в браузере.
- Настройки хранятся через `chrome.storage.local`.

## Отладка

Если что-то не работает:

1. Открой ChatGPT.
2. Нажми `F12`.
3. Перейди в Console.
4. В логах расширения ищи сообщения с префиксом:

```text
[ChatGPT DONE Auto-Continue]
```

Например:

```text
Generation detected.
Generation finished. Checking marker after delay.
Follow-up sent: Делай следующее задание
```
