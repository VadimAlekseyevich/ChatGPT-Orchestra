# ChatGPT DONE Auto-Continue

Расширение Manifest V3 для Microsoft Edge, которое распознаёт служебный флаг в последней строке ответа ChatGPT и выполняет привязанное к нему действие. Позволяет автоматически продолжать работу, повторять попытку после ошибки или остановиться и позвать пользователя.

## О проекте

Расширение предназначено для сценариев, где ChatGPT выполняет последовательность задач и после каждого шага должен либо продолжить работу, либо запросить участие пользователя.

После завершения реально наблюдавшейся генерации расширение читает последнюю непустую строку ответа и сравнивает её с включёнными правилами. Если строка совпадает с флагом, выполняется назначенное действие. Если совпадения нет, расширение ничего не делает.

## Статус проекта

Стадия проекта — **MVP**. Текущая версия расширения в `manifest.json` — **1.2.0**.

| Область | Статус |

Расширение распространяется как исходный код и загружается в Edge через **Load unpacked**.

## Возможности

- точное распознавание флага в последней непустой строке ответа;
- отдельное включение и отключение каждого правила;
- два действия для правила: отправить промпт или уведомить пользователя;
- базовые правила `DONE`, `FAIL` и `ERROR`;
- добавление собственных флагов, например `REVIEW`, `RETRY` или `NEXT_STAGE`;
- редактирование промпта или текста уведомления для каждого правила;
- настраиваемая базовая задержка и случайная добавка к ней;
- защита от автоматического запуска по старому ответу при открытии уже завершённого чата;
- отказ от автоотправки, если пользователь уже ввёл текст в поле сообщения;
- применение изменённых настроек к открытым вкладкам без перезагрузки;
- локальное хранение настроек через `chrome.storage.local`.

Сопоставление флагов чувствительно к регистру: `DONE` и `done` считаются разными значениями.

## Быстрый старт

1. Клонируй репозиторий:

```powershell
git clone https://github.com/VadimAlekseyevich/chatgpt_done_autocontinue.git
cd chatgpt_done_autocontinue
```

2. Открой в Microsoft Edge:

```text
edge://extensions/
```

3. Включи **Режим разработчика / Developer mode**.
4. Нажми **Загрузить распакованное / Load unpacked**.
5. Выбери папку репозитория, в которой находится `manifest.json`.
6. Обнови уже открытые вкладки ChatGPT.
7. Нажми на иконку расширения и проверь правила и задержки.

Сборка, Node.js и установка зависимостей не требуются.

## Требования

- Microsoft Edge с поддержкой расширений Manifest V3;
- включённый режим разработчика для установки из исходников;
- доступ к `https://chatgpt.com/` или `https://chat.openai.com/`.

Другие Chromium-браузеры могут быть совместимы с расширением, но основной целевой браузер проекта — Microsoft Edge.

## Использование

### Базовые правила

| Флаг | Действие | Значение по умолчанию |
|---|---|---|
| `DONE` | Отправить промпт | `Делай следующее задание` |
| `FAIL` | Позвать пользователя | `Требуется ваше участие. Откройте чат ChatGPT.` |
| `ERROR` | Отправить промпт | `Исправь ошибку и продолжи работу. Если без моего участия продолжить нельзя, заверши ответ флагом FAIL.` |

`DONE` подходит для перехода к следующему этапу, `FAIL` — для остановки автоматического цикла, когда требуется решение пользователя, `ERROR` — для автоматической попытки исправления.

### Пользовательские флаги

В окне расширения можно добавить собственное правило и задать:

- флаг;
- состояние правила;
- действие;
- промпт или текст уведомления.

Флаг должен занимать одну строку и быть уникальным среди правил. Расширение поддерживает до 50 правил.

### Инструкция для ChatGPT

Чтобы флаги распознавались однозначно, можно добавить в основной промпт такую инструкцию:

```text
Последней непустой строкой ответа пиши ровно один служебный флаг:

DONE
— текущая задача полностью выполнена и можно автоматически переходить дальше.

FAIL
— без моего ввода, решения, подтверждения или внешнего действия продолжить нельзя.

ERROR
— произошла ошибка, которую стоит попытаться исправить автоматически.

Не добавляй после флага текст, Markdown или знаки пунктуации.
```

Если используются собственные флаги, их значение и назначение также нужно описать в инструкции ChatGPT.

## Конфигурация

Настройки открываются нажатием на иконку расширения.

| Параметр | Назначение | Значение по умолчанию |
|---|---|---:|
| Обработка флагов | Глобально включает или отключает автоматизацию | Включена |
| Базовая задержка | Пауза после окончания генерации | `1200 мс` |
| Случайная добавка | Дополнительная случайная пауза | `0…1200 мс` |
| Правила | Набор флагов и назначенных действий | `DONE`, `FAIL`, `ERROR` |

Фактическая задержка перед каждой проверкой рассчитывается отдельно:

```text
базовая задержка + случайное значение от 0 до заданной добавки
```

При настройках по умолчанию проверка выполняется примерно через `1,2–2,4 с`. Значение случайной добавки `0` отключает рандомизацию.

Кнопка **Добавить** создаёт новое правило. Кнопка **Базовые правила** восстанавливает `DONE`, `FAIL` и `ERROR`; после восстановления нужно нажать **Сохранить**.

Настройки старой версии с полями `marker` и `followUp` автоматически мигрируют в новый формат правил при загрузке.

## Безопасность

Расширение не требует API-ключей, отдельного сервера или повышенных системных прав.

В `manifest.json` запрашиваются:

- разрешение `storage` для локального хранения настроек;
- доступ к `https://chatgpt.com/*`;
- доступ к `https://chat.openai.com/*`.

Автоматическая отправка не перезаписывает уже введённый пользователем текст: если поле сообщения непустое, действие пропускается.

## Приватность

- настройки хранятся локально через `chrome.storage.local`;
- расширение читает текст ответа из DOM текущей страницы ChatGPT только для проверки последней строки;
- внешнего сервера и сторонних библиотек нет;
- расширение не отправляет содержимое ответа во внешние сервисы самостоятельно.

Промпт, назначенный правилу, при автоотправке передаётся ChatGPT обычным способом через интерфейс сайта.

## Диагностика

Если правило не срабатывает:

1. Открой ChatGPT.
2. Нажми `F12`.
3. Перейди в **Console**.
4. Найди сообщения с префиксом:

```text
[ChatGPT DONE Auto-Continue]
```

Примеры сообщений:

```text
Generation detected.
Generation finished. Checking flag after randomized delay.
Flag check scheduled in 1847 ms.
Follow-up sent: Делай следующее задание
User notified for marker: FAIL
```

Расширение определяет генерацию по DOM-индикаторам интерфейса ChatGPT, в первую очередь по `data-testid="stop-button"`. Для отправки используются селекторы поля ввода и кнопки отправки с несколькими запасными вариантами.

Перед созданием issue укажи:

- сообщения из Console с префиксом `[ChatGPT DONE Auto-Continue]`, если они есть.

## Ограничения

- расширение зависит от DOM-разметки ChatGPT; после изменений интерфейса селекторы могут потребовать обновления;
- правило срабатывает только после генерации, которую расширение наблюдало в текущей вкладке;
- совпадение флага точное и чувствительно к регистру;
- флаг должен быть последней непустой строкой ответа;
- если поле ввода уже содержит текст, автоматическая отправка пропускается;
- другие Chromium-браузеры отдельно не заявлены как проверенные платформы;
- автоматическая работа не гарантирует, что сам ответ ChatGPT корректен: расширение реагирует только на указанный флаг.
