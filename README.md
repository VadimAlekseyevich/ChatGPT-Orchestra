# ChatGPT DONE Auto-Continue for Microsoft Edge

Manifest V3 расширение для Microsoft Edge, которое отслеживает флаг в конце ответа ChatGPT и выполняет настроенное действие.

## Что делает

Расширение следит за текущей вкладкой `chatgpt.com` и реагирует только после реально увиденной генерации ответа.

После окончания генерации оно берёт последнюю непустую строку ответа и сравнивает её с включёнными правилами. Для каждого флага можно выбрать одно из двух действий:

- **Отправить промпт** — автоматически вставить и отправить заданный текст в ChatGPT.
- **Позвать пользователя** — остановить автоматический цикл, сфокусировать вкладку и показать браузерный диалог.

Базовые правила:

| Флаг | Действие | Текст |
| --- | --- | --- |
| `DONE` | Отправить промпт | `Делай следующее задание` |
| `FAIL` | Позвать пользователя | `Требуется ваше участие. Откройте чат ChatGPT.` |
| `ERROR` | Отправить промпт | `Исправь ошибку и продолжи работу. Если без моего участия продолжить нельзя, заверши ответ флагом FAIL.` |

Все базовые правила можно редактировать. Можно добавлять собственные флаги, например `REVIEW`, `RETRY` или `NEXT_STAGE`, и назначать им свой промпт или уведомление.

Сопоставление точное и чувствительно к регистру: `DONE` и `done` — разные флаги.

## Установка в Microsoft Edge

1. Скачай репозиторий как ZIP или клонируй его.
2. Если скачал ZIP — распакуй его.
3. В Edge открой:

```text
edge://extensions/
```

4. Включи **Режим разработчика / Developer mode**.
5. Нажми **Загрузить распакованное / Load unpacked**.
6. Выбери папку этого репозитория — ту, где лежит `manifest.json`.
7. Обнови уже открытые вкладки ChatGPT.

Сборка, Node.js и установка зависимостей не нужны.

## Настройки

Нажми на иконку расширения в Edge. Можно изменить:

- включена ли автоматическая обработка флагов;
- список правил;
- флаг каждого правила;
- действие: отправить промпт или позвать пользователя;
- промпт или текст диалога;
- задержку после окончания генерации;
- состояние отдельного правила.

Кнопка **Добавить** создаёт новое правило. **Базовые правила** возвращает набор `DONE` / `FAIL` / `ERROR`; после этого нужно нажать **Сохранить**.

Настройки применяются к уже открытым вкладкам без их перезагрузки. Старые настройки версии 1.0 (`marker` и `followUp`) автоматически используются как правило продолжения при первом запуске новой версии и сохраняются в новом формате при следующем сохранении настроек.

## Рекомендуемая инструкция для ChatGPT

Добавь в основной промпт правила завершения ответа, например:

```text
Последней непустой строкой ответа пиши ровно один служебный флаг:

DONE
— текущая задача полностью выполнена и можно автоматически переходить дальше.

FAIL
— без моего ввода, решения, подтверждения или внешнего действия продолжить нельзя.

ERROR
— произошла ошибка, которую стоит попытаться исправить автоматически.

Не добавляй после флага текст, Markdown или знаки пунктуации.
```

Если добавляешь свои флаги в расширение, добавь их значение и смысл в инструкцию ChatGPT.

## Важное поведение

Расширение специально не выполняет действие только потому, что при открытии старого чата последний ответ уже заканчивается известным флагом. Оно должно увидеть текущую генерацию, а затем её завершение. Это защищает от случайного запуска старых чатов.

Если в поле ввода уже есть пользовательский текст, действие **Отправить промпт** ничего не перезаписывает и не отправляет.

Для `FAIL` и других правил с действием **Позвать пользователя** вкладка ChatGPT получает фокус и показывает диалог с текстом правила. Автоматическая отправка следующего сообщения при этом не выполняется.

## Поддерживаемые сайты

- `https://chatgpt.com/*`
- `https://chat.openai.com/*`

## Как определяется генерация

Расширение использует DOM-индикаторы интерфейса ChatGPT, в первую очередь кнопку `data-testid="stop-button"`. Для отправки используются актуальные селекторы `#prompt-textarea`, `#composer-submit-button` и `data-testid="send-button"` с запасными вариантами.

Интерфейс ChatGPT периодически меняется. Если OpenAI изменит DOM-разметку, селекторы в `content.js` может потребоваться обновить.

## Безопасность и приватность

- Никаких API-ключей.
- Никакого внешнего сервера.
- Никаких сторонних библиотек.
- Расширение работает локально в браузере.
- Настройки хранятся через `chrome.storage.local`.
- Текст ответа не отправляется во внешние сервисы.

## Отладка

Если что-то не работает:

1. Открой ChatGPT.
2. Нажми `F12`.
3. Перейди в Console.
4. В логах расширения ищи сообщения с префиксом:

```text
[ChatGPT DONE Auto-Continue]
```

Примеры:

```text
Generation detected.
Generation finished. Checking flag after delay.
Follow-up sent: Делай следующее задание
User notified for marker: FAIL
```
